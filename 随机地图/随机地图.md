# 随机地图生成设计文档

## 概述

本文档定义了基于Procedural Dungeon插件设计理念的随机地牢生成系统。地牢生成系统负责程序化创建游戏关卡，包括房间布局、门连接、敌人生成和战利品分布。

## 设计原则

1. **手工与程序结合** - 预制房间+程序化连接
2. **可复现生成** - 使用种子确保相同配置生成相同地牢
3. **规则驱动** - 通过规则系统控制房间连接和生成逻辑
4. **网络复制** - 确保多人游戏中地牢一致性
5. **性能优化** - 流式加载和卸载房间

## 核心架构

### 类层次结构

```
ADungeonGenerator (地牢生成器)
├── 生成算法控制
├── 房间实例管理
└── 网络复制

URoomData (房间数据资产)
├── 房间类型定义
├── 门位置配置
├── 生成规则
└── 内容配置

ARoom (房间实例)
├── 房间边界
├── 门连接点
├── 生成内容
└── 流式加载

ADoor (门Actor)
├── 门状态管理
├── 开关逻辑
└── 传送功能
```

## 生成算法

### 1. 主路径生成

```cpp
void ADungeonGenerator::GenerateMainPath()
{
    // 1. 生成起始房间
    URoomData* StartRoomData = SelectRoomFromPool(StartRoomPool);
    StartRoom = SpawnRoom(StartRoomData, FVector::ZeroVector, FRotator::ZeroRotator);
    StartRoom->Initialize(StartRoomData, 0);
    
    ARoom* CurrentRoom = StartRoom;
    
    // 2. 沿主路径生成房间
    for (int32 i = 1; i < MainPathLength; i++)
    {
        // 选择出口门
        TArray<ADoor*> AvailableDoors = CurrentRoom->GetDoors();
        ADoor* ExitDoor = AvailableDoors[RandomStream.RandRange(0, AvailableDoors.Num() - 1)];
        
        // 计算下一个房间位置
        FVector NextLocation = FindNextRoomLocation(CurrentRoom, ExitDoor);
        
        // 选择房间类型
        URoomData* NextRoomData;
        if (i == MainPathLength - 1)
        {
            // 最后一个房间是Boss房间
            NextRoomData = SelectRoomFromPool(BossRoomPool);
        }
        else
        {
            NextRoomData = SelectRoomFromPool(NormalRoomPool);
        }
        
        // 生成房间
        ARoom* NextRoom = SpawnRoom(NextRoomData, NextLocation, FRotator::ZeroRotator);
        if (NextRoom)
        {
            NextRoom->Initialize(NextRoomData, i);
            
            // 连接门
            ADoor* EntranceDoor = FindMatchingDoor(NextRoom, ExitDoor);
            ConnectRooms(CurrentRoom, ExitDoor, NextRoom, EntranceDoor);
            
            CurrentRoom = NextRoom;
        }
    }
    
    BossRoom = CurrentRoom;
}
```

### 2. 分支生成

```cpp
void ADungeonGenerator::GenerateBranches()
{
    int32 BranchesCreated = 0;
    
    while (BranchesCreated < MaxBranches)
    {
        // 从现有房间中随机选择一个作为分支起点
        ARoom* BranchStart = Rooms[RandomStream.RandRange(0, Rooms.Num() - 1)];
        
        // 查找未连接的门
        TArray<ADoor*> UnconnectedDoors;
        for (ADoor* Door : BranchStart->GetDoors())
        {
            if (!Door->GetConnectedRoom())
            {
                UnconnectedDoors.Add(Door);
            }
        }
        
        if (UnconnectedDoors.Num() == 0) continue;
        
        // 选择一个门创建分支
        ADoor* BranchDoor = UnconnectedDoors[RandomStream.RandRange(0, UnconnectedDoors.Num() - 1)];
        
        // 生成分支
        ARoom* CurrentRoom = BranchStart;
        int32 BranchDepth = RandomStream.RandRange(1, MaxBranchDepth);
        
        for (int32 i = 0; i < BranchDepth; i++)
        {
            FVector NextLocation = FindNextRoomLocation(CurrentRoom, BranchDoor);
            URoomData* NextRoomData = SelectRoomFromPool(NormalRoomPool);
            
            ARoom* NextRoom = SpawnRoom(NextRoomData, NextLocation, FRotator::ZeroRotator);
            if (NextRoom)
            {
                NextRoom->Initialize(NextRoomData, CurrentRoom->GetDepth() + 1);
                
                ADoor* EntranceDoor = FindMatchingDoor(NextRoom, BranchDoor);
                ConnectRooms(CurrentRoom, BranchDoor, NextRoom, EntranceDoor);
                
                CurrentRoom = NextRoom;
                BranchesCreated++;
                
                // 选择下一个出口门
                TArray<ADoor*> AvailableDoors = CurrentRoom->GetDoors();
                if (AvailableDoors.Num() == 0) break;
                BranchDoor = AvailableDoors[RandomStream.RandRange(0, AvailableDoors.Num() - 1)];
            }
            else
            {
                break;
            }
        }
    }
}
```

```cpp
void ARoom::SpawnEnemies()
{
    if (!RoomData || SpawnedEnemies.Num() > 0) return;
    
    // 确定敌人数量
    int32 EnemyCount = FMath::RandRange(RoomData->MinEnemies, RoomData->MaxEnemies);
    
    // 查找生成点
    TArray<AActor*> SpawnPoints;
    UGameplayStatics::GetAllActorsOfClassWithTag(GetWorld(), AActor::StaticClass(), 
                                                  FName("EnemySpawnPoint"), SpawnPoints);
    
    // 生成敌人
    for (int32 i = 0; i < EnemyCount && i < SpawnPoints.Num(); i++)
    {
        FFPSEnemySpawnInfo& SpawnInfo = RoomData->EnemySpawns[FMath::RandRange(0, RoomData->EnemySpawns.Num() - 1)];
        
        FActorSpawnParameters SpawnParams;
        SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AdjustIfPossibleButAlwaysSpawn;
        
        AFPSAICharacter* Enemy = GetWorld()->SpawnActor<AFPSAICharacter>(
            SpawnInfo.EnemyClass,
            SpawnPoints[i]->GetActorLocation(),
            SpawnPoints[i]->GetActorRotation(),
            SpawnParams
        );
        
        if (Enemy)
        {
            SpawnedEnemies.Add(Enemy);
            Enemy->OnDestroyed.AddDynamic(this, &ARoom::OnEnemyKilled);
        }
    }
    
    // 锁门
    if (RoomData->RoomType == ERoomType::Combat)
    {
        LockAllDoors();
    }
}

void ARoom::OnEnemyKilled(AActor* KilledEnemy)
{
    SpawnedEnemies.Remove(Cast<AFPSAICharacter>(KilledEnemy));
    
    // 检查是否清空
    if (SpawnedEnemies.Num() == 0)
    {
        SetCleared(true);
        UnlockAllDoors();
        SpawnLoot(); // 生成战利品
    }
}
```

```cpp
void ARoom::StreamInContent()
{
    if (!RoomData || !RoomData->Level.IsValid()) return;
    
    // 异步加载关卡
    FLatentActionInfo LatentInfo;
    LatentInfo.CallbackTarget = this;
    LatentInfo.ExecutionFunction = "OnLevelLoaded";
    LatentInfo.Linkage = 0;
    LatentInfo.UUID = GetUniqueID();
    
    UGameplayStatics::LoadStreamLevel(this, RoomData->Level.GetAssetName(), true, true, LatentInfo);
}

void ARoom::StreamOutContent()
{
    if (!RoomData || !RoomData->Level.IsValid()) return;
    
    // 卸载关卡
    FLatentActionInfo LatentInfo;
    UGameplayStatics::UnloadStreamLevel(this, RoomData->Level.GetAssetName(), LatentInfo, false);
}
```
