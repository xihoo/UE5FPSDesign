# RoomData.cpp

该文件包含了 `URoomData` 类的实现，该类是房间数据资产，定义了房间的大小、门和其他参数。

## 主要功能

- **门管理**：管理房间的门定义，包括兼容性检查和获取兼容门列表。
- **自定义数据**：管理房间的自定义数据类。
- **房间初始化和清理**：提供房间实例初始化和清理的接口。
- **边界计算**：计算房间的边界框和体素边界。
- **数据验证**：在编辑器中验证房间数据的有效性。

## 详细实现

### 门管理

- `GetDoorDef`：根据索引获取门定义。
- `HasCompatibleDoor`：检查是否存在与给定门定义兼容的门。
- `GetCompatibleDoors`：获取与给定门定义兼容的门索引列表。
- `HasDoorOfType`：检查是否存在指定类型的门。
- `HasAnyDoorOfType`：检查是否存在指定类型列表中的任意一种门。
- `HasAllDoorOfType`：检查是否包含指定类型列表中的所有门。

### 自定义数据

- `HasCustomData`：检查是否存在指定类型的自定义数据。
- `HasAnyCustomData`：检查是否存在指定类型列表中的任意一种自定义数据。
- `HasAllCustomData`：检查是否包含指定类型列表中的所有自定义数据。

### 房间初始化和清理

- `InitializeRoom`：虚函数，用于初始化房间实例。
- `CleanupRoom`：虚函数，用于清理房间实例。

### 边界计算

- `GetBounds`：获取房间的世界边界框。
- `GetSize`：获取房间的大小。
- `GetVolume`：获取房间的体积。
- `GetIntBounds`：获取房间的整数边界框。
- `GetVoxelBounds`：获取房间的体素边界。如果缓存无效，则根据整数边界和门信息计算体素边界。
- `IsRoomInBounds`：检查房间是否在给定边界内。

### 数据验证

- `IsDoorValid`：检查门定义是否有效（在房间边界内且在边缘）。
- `IsDoorDuplicate`：检查是否存在重复的门定义。
- `IsDataValid`：验证房间数据的有效性，包括关卡、大小、门和自定义数据。
- `PostEditChangeProperty`：属性更改后的回调函数，用于重置缓存的体素边界。

这个类是地牢生成系统中定义房间模板的核心组件，包含了房间的所有静态数据和验证逻辑。
