# ProceduralDungeon 插件学习流程

## 概述

本文档旨在为开发者提供一个高效、系统的学习路径，以便快速掌握 ProceduralDungeon 插件的架构、核心概念和使用方法。该插件允许在 Unreal Engine 中创建结合手工设计和程序化生成元素的地牢。

## 学习目标

1.  理解插件的整体架构和模块划分。
2.  掌握核心类（如 `ADungeonGenerator`, `URoom`, `URoomData`, `ADoor`）的作用和交互方式。
3.  熟悉地牢生成的流程和可定制点。
4.  了解编辑器扩展功能（如 Room Editor Mode）的使用。
5.  能够进行基本的地牢设计、配置和调试。

## 学习路径

### 第一阶段：基础概念与架构 (1-2 天)

**目标**: 建立对插件整体结构和基本概念的清晰认识。

1.  **阅读入门文档**:
    *   从 `ReadMe.md` 和 `IFLOW.md` 开始，了解插件的基本功能、构建方式和核心思想。
2.  **理解核心类**:
    *   **`URoomData`**: 房间模板。阅读 `Doc/RoomData.md` 和 `Source/ProceduralDungeon/Public/RoomData.h`。理解 `FirstPoint`, `SecondPoint`, `Doors` 等属性。
    *   **`URoom`**: 房间实例。阅读 `Doc/Room.md` 和 `Source/ProceduralDungeon/Public/Room.h`。理解它如何持有 `URoomData` 的实例化数据，如 `Position`, `Direction`, `Connections`。
    *   **`ADungeonGenerator`**: 地牢生成器。阅读 `Doc/DungeonGenerator.md` 和 `Source/ProceduralDungeon/Public/DungeonGenerator.h`。理解 `ChooseFirstRoomData`, `ChooseNextRoomData`, `IsValidDungeon` 等关键蓝图事件。
    *   **`UDungeonGraph`**: 房间和连接的图结构。阅读 `Doc/DungeonGraph.md`。
    *   **`ADoor`**: 门基类。阅读 `Doc/Door.md`。
3.  **模块结构**:
    *   理解 `Source/ProceduralDungeon` (运行时) 和 `Source/ProceduralDungeonEditor` (编辑器) 两个模块的职责。
4.  **接口**:
    *   快速浏览 `IReadOnlyRoom`, `IDungeonCustomSerialization`, `IDungeonSaveInterface` 等接口，了解它们提供的功能。

### 第二阶段：地牢生成流程 (2-3 天)

**目标**: 深入理解地牢是如何一步步生成的，以及如何通过蓝图进行定制。

1.  **生成器核心逻辑**:
    *   详细阅读 `Doc/DungeonGenerator_cpp.md` 和 `Source/ProceduralDungeon/Private/DungeonGenerator.cpp` 中的 `CreateDungeon_Implementation` 和 `AddNewRooms` 方法，理解 DFS/BFS 生成循环。
2.  **蓝图事件**:
    *   重点理解 `ADungeonGenerator` 中的 `ChooseFirstRoomData`, `ChooseNextRoomData`, `IsValidDungeon`, `ContinueToAddRoom` 等蓝图原生事件。这些是用户控制生成逻辑的主要入口。
3.  **门的处理**:
    *   阅读 `Doc/Door_cpp.md` 和 `Source/ProceduralDungeon/Private/Door.cpp`，理解门的可见性、锁定和打开状态是如何管理的。
    *   了解 `UDoorType` (`Doc/DoorType.md`) 如何定义门的外观和行为。
4.  **连接与图**:
    *   阅读 `Doc/DungeonGraph_cpp.md` 和 `Source/ProceduralDungeon/Private/DungeonGraph.cpp`，理解 `URoomConnection` (`Doc/RoomConnection.md`) 如何表示房间间的连接，以及 `UDungeonGraph` 如何管理整个地牢结构。
5.  **房间加载与初始化**:
    *   理解 `URoom::Instantiate` 和 `ADungeonGeneratorBase::FinalizeDungeon` 如何加载关卡并调用 `URoomData::InitializeRoom`。

### 第三阶段：编辑器功能与工具 (1-2 天)

**目标**: 掌握如何使用编辑器工具来设计和配置房间。

1.  **Room Editor Mode**:
    *   阅读 `Doc/ProceduralDungeonEdMode_h.md`, `Doc/ProceduralDungeonEdMode_cpp.md`, `Doc/ProceduralDungeonEdModeToolkit_h.md`, `Doc/ProceduralDungeonEdModeToolkit_cpp.md`。理解编辑器模式是如何设置的。
2.  **Size Tool 和 Door Tool**:
    *   阅读 `Doc/ProceduralDungeonEditorTool_Size_h.md`, `Doc/ProceduralDungeonEditorTool_Size_cpp.md`, `Doc/ProceduralDungeonEditorTool_Door_h.md`, `Doc/ProceduralDungeonEditorTool_Door_cpp.md`。理解这两个工具是如何与 `ARoomLevel` 和 `URoomData` 交互的。
3.  **SProceduralDungeonEdModeWidget**:
    *   阅读 `Doc/SProceduralDungeonEdModeWidget_h.md` 和 `Doc/SProceduralDungeonEdModeWidget_cpp.md`。理解主 UI 界面的构成和功能，特别是 "Update Selected Volumes" 和 "Remove All Invalid Doors" 按钮的作用。
4.  **资产创建**:
    *   了解 `URoomDataFactory` (`Doc/RoomDataFactory_h.md`, `Doc/RoomDataFactory_cpp.md`) 和 `UDoorTypeFactory` (`Doc/DoorTypeFactory_h.md`, `Doc/DoorTypeFactory_cpp.md`) 如何在内容浏览器中创建资产。

### 第四阶段：高级特性与调试 (1-2 天)

**目标**: 了解插件的高级功能和调试方法。

1.  **自定义数据 (Custom Data)**:
    *   阅读 `Doc/RoomCustomData.md`, `Doc/RoomCustomData_cpp.md`。理解如何为房间添加自定义数据和组件。
2.  **可见性与剔除 (Visibility & Occlusion)**:
    *   阅读 `Doc/RoomLevel_cpp.md`, `Doc/RoomVisibilityComponent_cpp.md`, `Doc/Components/StaticRoomVisibilityComponent_cpp.md`。理解房间和 Actor 的可见性是如何管理的。
    *   了解 `FProceduralDungeonSettings` (`Doc/ProceduralDungeonSettings.md`) 中的 `OcclusionCulling`, `OcclusionDistance` 等设置。
3.  **保存与加载 (Save/Load)**:
    *   阅读 `Doc/Interfaces/DungeonSaveInterface_cpp.md`, `Doc/Interfaces/DungeonCustomSerialization_cpp.md`, `Doc/Utils/DungeonSaveUtils_cpp.md`。理解插件的序列化机制。
4.  **调试**:
    *   了解 `FProceduralDungeonSettings` 中的 `DrawDebug` 相关设置。
    *   阅读 `Doc/ProceduralDungeonLog.md` 了解日志系统。

### 第五阶段：实践与项目应用 (持续)

**目标**: 通过实际项目应用所学知识。

1.  **创建一个简单地牢**:
    *   设计几个基础 `URoomData`。
    *   创建一个继承自 `ADungeonGenerator` 的蓝图类，并实现 `ChooseFirstRoomData`, `ChooseNextRoomData` 等事件。
    *   运行游戏，观察生成结果。
2.  **添加自定义元素**:
    *   尝试添加自定义门类型 (`UDoorType`)。
    *   尝试为房间添加自定义数据和组件。
3.  **优化与调试**:
    *   使用编辑器工具优化房间设计。
    *   根据生成结果调整蓝图逻辑。

## 学习建议

*   **动手实践**: 理论学习与实际操作相结合，边学边做。
*   **查阅源码**: 文档可能不够详尽，直接阅读源代码 `.h` 和 `.cpp` 文件是理解细节的最佳方式。
*   **利用编辑器**: 多使用 Room Editor Mode 和插件提供的工具，熟悉其操作和功能。
*   **关注接口**: 插件大量使用接口（如 `IReadOnlyRoom`, `IDungeonSaveInterface`），理解它们的作用域和使用方法非常重要。
*   **循序渐进**: 不要试图一次性掌握所有内容，按阶段逐步深入。
