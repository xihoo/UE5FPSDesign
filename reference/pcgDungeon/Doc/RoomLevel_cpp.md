# RoomLevel.cpp

该文件包含了 `ARoomLevel` 类的实现，该类是房间关卡的蓝图脚本基类。

## 主要功能

- **房间初始化**：初始化房间实例并设置相关属性。
- **触发器管理**：创建和管理用于检测动态Actor进入和离开房间的触发器。
- **可见性管理**：控制房间内Actor的可见性。
- **调试绘制**：在编辑器中绘制房间和门的调试信息。
- **访客管理**：管理进入和离开房间的访客（Actor或组件）。

## 详细实现

### 初始化

- `ARoomLevel`：构造函数，设置根组件并初始化成员变量。
- `Init`：初始化房间实例，设置地牢变换并更新边界。
- `BeginPlay`：游戏开始时的初始化逻辑。
  - 检查房间实例是否有效。
  - 验证房间数据是否匹配。
  - 创建用于检测Actor进入和离开的触发器盒（`UBoxComponent`）。
  - 设置触发器的碰撞属性。
  - 绑定触发器的重叠事件。
  - 更新触发器盒的大小和位置以匹配房间边界。
  - 根据房间可见性设置Actor可见性。
  - 创建房间自定义数据的关卡组件。
  - 标记房间已初始化。
- `EndPlay`：游戏结束时的清理逻辑，将房间实例设置为无效。

### 调试绘制

- `Tick`：每帧调用，用于绘制调试信息。
  - 根据设置决定是否绘制调试信息。
  - 绘制房间原点、边界和门。
  - 绘制房间锁定状态的对角线。

### 可见性管理

- `SetActorsVisible`：设置房间内所有Actor的可见性。
  - 如果禁用了遮挡剔除，则强制可见。
  - 遍历关卡中的所有Actor，设置其隐藏状态。
  - 忽略复制的Actor和标记为"忽略房间剔除"的Actor。
  - 广播可见性更改事件。

### 触发器管理

- `OnTriggerBeginOverlap`：Actor进入触发器时的回调函数。
- `OnTriggerEndOverlap`：Actor离开触发器时的回调函数。
- `TriggerActor`：触发Actor进入或离开房间的事件。
  - 调用Actor自身的 `IRoomVisitor` 接口。
  - 调用Actor组件的 `IRoomVisitor` 接口。
  - 广播Actor进入或离开房间的事件。

### 访客管理

- `UpdateVisitor`：更新访客（Actor或组件）的进入或离开状态。
  - 如果是进入且访客不在列表中，则添加访客并调用 `OnRoomEnter`。
  - 如果是离开且访客在列表中，则移除访客并调用 `OnRoomExit`。

### 工具函数

- `IsPlayerInside`：检查玩家是否在房间内。
- `IsVisible`：检查房间是否可见。
- `IsLocked`：检查房间是否被锁定。
- `Lock`：锁定或解锁房间。
- `GetBoundsCenter`：获取房间边界中心的世界坐标。
- `GetBoundsExtent`：获取房间边界的范围。
- `UpdateBounds`：更新房间边界。
- `PostInitProperties`：属性初始化后的回调函数，用于更新边界。
- `PostEditChangeProperty`：编辑器中属性更改后的回调函数，用于更新边界和广播事件。

这个类是连接房间数据和实际关卡实例的桥梁，负责管理房间的生命周期、可见性和交互。
