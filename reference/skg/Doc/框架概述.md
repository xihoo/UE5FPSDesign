# SKGShooterFramework 框架概述

SKGShooterFramework 是一个专为 Unreal Engine 5.6 设计的多人射击游戏框架插件，由 Sneaky Kitty Game Dev 开发。该框架提供了一套模块化、可扩展的组件和系统，用于构建高质量的射击游戏。

## 框架特点

### 模块化架构
- **组件化设计**: 所有功能通过 `USceneComponent` 子类实现
- **数据驱动**: 大量使用 Unreal Engine 数据资产配置行为
- **网络支持**: 完整的网络复制功能，支持多人游戏
- **可扩展性**: 易于添加新功能和自定义行为

### 核心功能模块
1. **动画系统** - 程序化动画和动画图表节点
2. **附件系统** - 武器附件管理
3. **火器系统** - 射击机制和弹道模拟
4. **光学系统** - 瞄准镜和光学设备
5. **物理材质** - 碰撞和材质交互
6. **统计系统** - 游戏数据统计

### 数据资产配置
使用 Unreal Engine 的数据资产系统配置组件行为：
- `USKGPDAXXXSettings` - 设置数据资产
- `USKGPDAXXXInitialize` - 初始化数据资产
- 支持运行时动态配置

### 网络同步
所有关键组件都支持网络复制：
- 使用 `GetLifetimeReplicatedProps` 定义复制属性
- 支持推送模型优化
- 客户端-服务器架构支持
