## 快速开始

### 1. 环境要求
- Unreal Engine 5.6+
- C++ 开发环境
- 基础射击游戏开发经验

### 2. 安装和配置
1. 将插件复制到项目的 `Plugins` 目录
2. 在 `.uproject` 文件中启用插件
3. 重新生成项目文件并编译
4. 在编辑器中配置必要的设置

### 3. 基础使用流程
1. **创建武器Actor**: 使用框架提供的基础类
2. **添加核心组件**: 火器、附件、程序化动画等组件
3. **配置数据资产**: 设置武器参数、动画配置等
4. **实现游戏逻辑**: 射击、换弹、瞄准等功能
5. **测试和优化**: 确保网络同步和性能表现
