# 库存系统设计文档

## 概述

本文档定义了基于定义/实例（Definition/Instance）模式的库存管理系统。库存系统负责管理玩家的物品、装备、武器、消耗品等，并与GAS深度集成实现物品效果。

## 设计原则

1. **定义/实例分离** - Item Definition定义物品属性，Item Instance存储实例数据
2. **GAS集成** - 物品效果通过GameplayEffect和GameplayAbility实现
3. **数据驱动** - 物品配置通过DataAsset管理
4. **网络复制** - 确保多人游戏中库存同步
5. **插槽系统** - 支持装备槽、快捷栏等多种插槽类型

## 核心架构

### 类层次结构

```
UFPSInventoryComponent (库存组件)
├── 管理物品实例列表
├── 处理物品添加/移除
├── 管理装备槽位
└── 网络复制

UFPSItemDefinition (物品定义DataAsset)
├── 物品基础信息
├── 物品类型
├── 堆叠上限
├── GameplayEffects
└── GameplayAbilities

UFPSItemInstance (物品实例)
├── 引用ItemDefinition
├── 堆叠数量
├── 实例唯一数据
├── 耐久度/品质等
└── 附加属性

EItemType (物品类型枚举)
├── 武器
├── 护甲
├── 消耗品
├── 材料
└── 任务物品
```

### 2. 物品掉落

```cpp
void UFPSInventoryComponent::DropItem(UFPSItemInstance* Item, int32 Quantity)
{
    if (!Item || Quantity <= 0) return;
    
    // 生成掉落物
    FVector DropLocation = GetOwner()->GetActorLocation() + GetOwner()->GetActorForwardVector() * 100.0f;
    FRotator DropRotation = FRotator::ZeroRotator;
    
    FActorSpawnParameters SpawnParams;
    SpawnParams.SpawnCollisionHandlingOverride = ESpawnActorCollisionHandlingMethod::AdjustIfPossibleButAlwaysSpawn;
    
    AFPSItemPickup* Pickup = GetWorld()->SpawnActor<AFPSItemPickup>(
        Item->GetItemDefinition()->WorldDropClass,
        DropLocation,
        DropRotation,
        SpawnParams
    );
    
    if (Pickup)
    {
        Pickup->InitializePickup(Item->GetItemDefinition(), Quantity);
        
        // 添加抛出力
        if (UStaticMeshComponent* Mesh = Pickup->FindComponentByClass<UStaticMeshComponent>())
        {
            Mesh->AddImpulse(GetOwner()->GetActorForwardVector() * 500.0f + FVector::UpVector * 200.0f, NAME_None, true);
        }
    }
    
    // 从库存移除
    RemoveItem(Item, Quantity);
}
```

### 1. 装备物品

```cpp
bool UFPSInventoryComponent::EquipItem(UFPSItemInstance* Item, EEquipmentSlot Slot)
{
    if (!Item || !Item->GetItemDefinition()->bCanEquip) return false;
    
    // 验证槽位
    if (Item->GetItemDefinition()->EquipmentSlot != Slot) return false;
    
    // 卸下当前装备
    if (UFPSItemInstance* CurrentItem = GetEquippedItem(Slot))
    {
        UnequipItem(Slot);
    }
    
    // 装备新物品
    EquippedItems.Add(Slot, Item);
    
    // 应用装备效果
    ApplyItemEffects(Item, true);
    
    // 触发事件
    OnItemEquipped.Broadcast(Item, Slot);
    
    // 如果是武器，生成武器Actor
    if (Item->GetItemDefinition()->IsWeapon())
    {
        SpawnWeaponActor(Item);
    }
    
    return true;
}

void UFPSInventoryComponent::ApplyItemEffects(UFPSItemInstance* Item, bool bApply)
{
    if (!Item) return;
    
    UFPSItemDefinition* Definition = Item->GetItemDefinition();
    if (!Definition) return;
    
    // 获取AbilitySystemComponent
    if (UAbilitySystemComponent* ASC = GetOwner()->FindComponentByClass<UAbilitySystemComponent>())
    {
        if (bApply)
        {
            // 授予能力
            for (TSubclassOf<UGameplayAbility> AbilityClass : Definition->GrantedAbilities)
            {
                if (AbilityClass)
                {
                    FGameplayAbilitySpec Spec(AbilityClass, 1, INDEX_NONE, this);
                    ASC->GiveAbility(Spec);
                }
            }
            
            // 应用装备效果
            for (TSubclassOf<UGameplayEffect> EffectClass : Definition->OnEquipEffects)
            {
                if (EffectClass)
                {
                    FGameplayEffectContextHandle EffectContext = ASC->MakeEffectContext();
                    EffectContext.AddSourceObject(Item);
                    
                    FGameplayEffectSpecHandle SpecHandle = ASC->MakeOutgoingSpec(EffectClass, 1, EffectContext);
                    if (SpecHandle.IsValid())
                    {
                        ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
                    }
                }
            }
        }
        else
        {
            // 移除能力和效果
            // TODO: 实现移除逻辑
        }
    }
}
```

```cpp
    if (!ItemDef || Quantity <= 0 || Quantity > 999)
    {
        return false;
    }
    
    return true;
}

void UFPSInventoryComponent::ServerAddItem_Implementation(UFPSItemDefinition* ItemDef, int32 Quantity)
{
    AddItem(ItemDef, Quantity);
}
```

```cpp
void UFPSInventoryComponent::SaveInventory(FFPSInventorySaveData& OutSaveData)
{
    for (UFPSItemInstance* Item : Items)
    {
        FFPSItemSaveData ItemData;
        ItemData.ItemDefinitionPath = Item->GetItemDefinition()->GetPathName();
        ItemData.Quantity = Item->GetQuantity();
        ItemData.Durability = Item->GetDurability();
        ItemData.Quality = Item->GetQuality();
        ItemData.InstanceID = Item->GetInstanceID();
        ItemData.CustomData = Item->GetAllCustomData();
        
        OutSaveData.SavedItems.Add(ItemData);
    }
    
    // 保存装备槽
    for (const auto& Pair : EquippedItems)
    {
        OutSaveData.EquippedItemIDs.Add(Pair.Key, Pair.Value->GetInstanceID());
    }
}

void UFPSInventoryComponent::LoadInventory(const FFPSInventorySaveData& SaveData)
{
    // 清空当前库存
    Items.Empty();
    EquippedItems.Empty();
    
    // 加载物品
    for (const FFPSItemSaveData& ItemData : SaveData.SavedItems)
    {
        UFPSItemDefinition* Definition = LoadObject<UFPSItemDefinition>(nullptr, *ItemData.ItemDefinitionPath);
        if (Definition)
        {
            UFPSItemInstance* NewItem = CreateItemInstance(Definition, ItemData.Quantity);
            NewItem->SetDurability(ItemData.Durability);
            NewItem->SetQuality(ItemData.Quality);
            // ... 加载自定义数据
            
            Items.Add(NewItem);
        }
    }
    
    // 恢复装备
    // ... 实现装备恢复逻辑
}
```
