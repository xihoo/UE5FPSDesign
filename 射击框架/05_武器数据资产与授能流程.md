# 射击框架 · 武器数据资产与授能流程

## UFPSWeaponData（核心字段）

```cpp
UCLASS(BlueprintType)
class PROJECTNAME_API UFPSWeaponData : public UPrimaryDataAsset
{
    GENERATED_BODY()
public:
    // 基础信息/网格/动画/音效/特效（略）

    // 射击与弹药参数（初始值，最终值由属性覆盖）
    float FireRate = 600.0f;
    float BaseDamage = 30.0f;
    float Range = 10000.0f;
    int32 BulletsPerShot = 1;
    int32 MagazineSize = 30;
    float ReloadTime = 2.5f;

    // GAS 集成
    TSubclassOf<UGameplayAbility> FireAbility;
    TSubclassOf<UGameplayAbility> ReloadAbility;
    TSubclassOf<UGameplayEffect> DamageEffect;

    // 扩展（建议新增）
    TSubclassOf<UGameplayEffect> WeaponBaseStatsEffect; // 装备时应用、卸下时移除
    TArray<TSubclassOf<UGameplayAbility>> GrantedAbilities; // Fire/Reload/Aim 等
    FGameplayTagContainer WeaponTags; // Weapon.Rifle, Weapon.Automatic 等
};
```

## 装备/卸下流程

1) EquipWeapon
- 授予 GrantedAbilities 到 ASC
- 应用 WeaponBaseStatsEffect 写入属性（BaseDamage/FireRate 等）
- 添加 WeaponTags 与 State.Weapon.HasWeapon

2) UnequipWeapon
- 从 ASC 移除授予的能力
- 移除 WeaponBaseStatsEffect
- 移除标签
