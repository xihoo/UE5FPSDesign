# 射击框架设计文档

## 概述

本文档定义了基于SKG Shooter Framework设计理念，并深度集成GAS的射击系统架构。射击框架负责处理武器管理、射击机制、弹道计算、后坐力、瞄准系统等FPS游戏核心功能。

## 设计原则

1. **模块化组件设计** - 参考SKG框架的组件化思想，武器由多个独立组件组成
2. **GAS深度集成** - 射击动作通过GameplayAbility实现
3. **数据驱动配置** - 武器参数通过DataAsset配置
4. **网络复制优先** - 确保多人游戏中射击同步
5. **程序化动画支持** - 实现武器的程序化后坐力和瞄准动画

## 核心架构

### 组件层次结构

```
AFPSPlayerCharacter
├── UFPSShooterPawnComponent (射击角色组件)
│   ├── 管理当前持有武器
│   ├── 处理瞄准状态
│   ├── 控制程序化动画
│   └── 处理自由视角
└── UFPSFirearmComponent (火器组件)
    ├── 射击逻辑
    ├── 弹药管理
    ├── 后坐力处理
    └── 准星扩散

AFPSWeapon (武器Actor)
├── USkeletalMeshComponent (武器网格)
├── UFPSMuzzleComponent (枪口组件)
│   ├── 枪口火光特效
│   └── 弹壳抛出
├── UFPSOpticComponent (瞄具组件)
│   ├── 瞄准镜渲染
│   └── 倍率切换
├── UFPSStockComponent (枪托组件)
│   └── 后坐力调整
├── UFPSAttachmentManagerComponent (配件管理器)
│   └── 管理所有配件
└── Data: UFPSWeaponData (武器数据资产)
```

## 弹道系统

### 1. Hitscan（即时命中）

```cpp
void UFPSFirearmComponent::PerformHitscan()
{
    if (!OwningCharacter) return;
    
    // 获取射击起点和方向
    FVector Start = GetMuzzleLocation();
    FVector Direction = GetMuzzleDirection();
    
    // 应用准星扩散
    Direction = ApplySpread(Direction, CurrentSpread);
    
    FVector End = Start + Direction * Range;
    
    // 执行射线检测
    FHitResult HitResult;
    FCollisionQueryParams QueryParams;
    QueryParams.AddIgnoredActor(GetOwner());
    QueryParams.bTraceComplex = true;
    QueryParams.bReturnPhysicalMaterial = true;
    
    bool bHit = GetWorld()->LineTraceSingleByChannel(
        HitResult,
        Start,
        End,
        ECC_GameTraceChannel1, // 自定义武器追踪通道
        QueryParams
    );
    
    if (bHit)
    {
        // 应用伤害
        ApplyDamage(HitResult);
        
        // 播放命中效果
        SpawnImpactEffects(HitResult);
    }
    
    // 播放枪口特效
    SpawnMuzzleEffects();
    
    // 添加后坐力
    ApplyRecoil();
    
    // 增加准星扩散
    AddSpread(SpreadIncreasePerShot);
}

FVector UFPSFirearmComponent::ApplySpread(const FVector& Direction, float Spread)
{
    // 随机偏移
    float RandomX = FMath::RandRange(-Spread, Spread);
    float RandomY = FMath::RandRange(-Spread, Spread);
    
    FRotator Rotation = Direction.Rotation();
    Rotation.Pitch += RandomY;
    Rotation.Yaw += RandomX;
    
    return Rotation.Vector();
}
```

## 后坐力系统

### 1. 相机后坐力

```cpp
void UFPSShooterPawnComponent::ApplyRecoil(FVector LocationRecoil, FRotator RotationRecoil)
{
    // 添加到累积后坐力
    CurrentRecoilLocation += LocationRecoil;
    CurrentRecoilRotation += RotationRecoil;
    
    // 应用到控制器
    if (APlayerController* PC = Cast<APlayerController>(GetOwner()->GetInstigatorController()))
    {
        // 垂直后坐力
        float VerticalRecoil = FMath::RandRange(RotationRecoil.Pitch * 0.8f, RotationRecoil.Pitch * 1.2f);
        PC->AddPitchInput(-VerticalRecoil);
        
        // 水平后坐力
        float HorizontalRecoil = FMath::RandRange(RotationRecoil.Yaw * 0.8f, RotationRecoil.Yaw * 1.2f);
        PC->AddYawInput(HorizontalRecoil);
    }
}

void UFPSShooterPawnComponent::UpdateProceduralAnimation(float DeltaTime)
{
    // 后坐力恢复
    float RecoveryAlpha = DeltaTime * RecoilRecoverySpeed;
    
    CurrentRecoilLocation = FMath::VInterpTo(
        CurrentRecoilLocation,
        FVector::ZeroVector,
        DeltaTime,
        RecoilRecoverySpeed
    );
    
    CurrentRecoilRotation = FMath::RInterpTo(
        CurrentRecoilRotation,
        FRotator::ZeroRotator,
```

## 瞄准系统

### 1. 瞄准插值

```cpp
void UFPSShooterPawnComponent::UpdateAiming(float DeltaTime)
{
    float TargetProgress = bIsAiming ? 1.0f : 0.0f;
    
    AimingProgress = FMath::FInterpTo(
        AimingProgress,
        TargetProgress,
        DeltaTime,
        AimSpeed
    );
    
    // 更新FOV
    if (APlayerController* PC = Cast<APlayerController>(GetOwner()->GetInstigatorController()))
    {
        if (APlayerCameraManager* CameraManager = PC->PlayerCameraManager)
        {
            float TargetFOV = bIsAiming ? AimedFOV : DefaultFOV;
            CameraManager->SetFOV(FMath::Lerp(DefaultFOV, TargetFOV, AimingProgress));
        }
    }
    
    // 更新武器位置
    UpdateWeaponPosition();
}

void UFPSShooterPawnComponent::UpdateWeaponPosition()
{
    if (!CurrentWeapon) return;
    
    // 插值武器位置到瞄准位置
    FVector AimOffset = CurrentWeapon->GetAimOffset();
    FVector CurrentOffset = FMath::VInterpTo(
        CurrentLocationOffset,
        AimOffset * AimingProgress,
        GetWorld()->GetDeltaSeconds(),
        10.0f
    );
    
    SetProceduralOffset(CurrentOffset, FRotator::ZeroRotator);
}
```

### 2. 瞄准辅助（手柄）

```cpp
void UFPSShooterPawnComponent::ApplyAimAssist(FVector& OutLookDirection)
{
    if (!bEnableAimAssist || !IsUsingGamepad()) return;
    
    // 查找最近的敌人
    AActor* NearestEnemy = FindNearestEnemy(AimAssistRange);
    
    if (NearestEnemy)
    {
        FVector ToEnemy = (NearestEnemy->GetActorLocation() - GetOwner()->GetActorLocation()).GetSafeNormal();
        float DotProduct = FVector::DotProduct(OutLookDirection, ToEnemy);
        
        // 在一定角度内提供瞄准辅助
        if (DotProduct > AimAssistAngle)
        {
            OutLookDirection = FMath::VInterpTo(
                OutLookDirection,
                ToEnemy,
                GetWorld()->GetDeltaSeconds(),
                AimAssistStrength
            );
        }
    }
}
```
