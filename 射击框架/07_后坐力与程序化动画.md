# 射击框架 · 后坐力与程序化动画

## 相机/武器后坐力

```cpp
void UFPSShooterPawnComponent::ApplyRecoil(FVector LocRecoil, FRotator RotRecoil)
{
    CurrentRecoilLocation += LocRecoil;
    CurrentRecoilRotation += RotRecoil;
    if (APlayerController* PC = Cast<APlayerController>(GetOwner()->GetInstigatorController()))
    {
        float V = FMath::RandRange(RotRecoil.Pitch * 0.8f, RotRecoil.Pitch * 1.2f);
        float H = FMath::RandRange(RotRecoil.Yaw * 0.8f, RotRecoil.Yaw * 1.2f);
        PC->AddPitchInput(-V); PC->AddYawInput(H);
    }
}

void UFPSShooterPawnComponent::UpdateProceduralAnimation(float Dt)
{
    CurrentRecoilLocation = FMath::VInterpTo(CurrentRecoilLocation, FVector::ZeroVector, Dt, RecoilRecoverySpeed);
    CurrentRecoilRotation = FMath::RInterpTo(CurrentRecoilRotation, FRotator::ZeroRotator, Dt, RecoilRecoverySpeed);
}
```

## 从 GAS 属性驱动后坐力

```cpp
// 在 Fire Ability 中读取属性并调用：
ShooterComp->ApplyRecoilFromAttributes(VMin, VMax, HMin, HMax);
```

建议：后坐力恢复速度 RecoilRecoverySpeed 亦为属性，受附件/姿态/状态影响。
