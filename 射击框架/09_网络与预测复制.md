# 射击框架 · 网络与预测复制

## 两种路径

1. 传统组件 RPC：`ServerFire` + `MulticastFireEffects`（仅做回兼容）
2. 推荐 GAS 预测：客户端 TryActivateAbilitiesByTag → 服务器验证 → GameplayCue 广播特效

## 推荐流程（GA_Weapon_Fire）
1. 客户端输入触发：Started → ASC.TryActivateAbilitiesByTag
2. 客户端立即播放轻特效（枪口闪光、局部后坐力）
3. 服务器验证 Ammo/状态/冷却
4. 服务器执行命中判定与伤害应用（GameplayEffect）
5. 服务器触发 GameplayCue：GC.Weapon.MuzzleFlash / GC.Weapon.Impact
6. 客户端如被拒绝：ASC 自动回滚 EndAbility

## GameplayCue 建议
- GC.Weapon.MuzzleFlash：枪口粒子 + 声音
- GC.Weapon.Impact：命中材质特效
- GC.Weapon.Reload：重装音效/动画

## 带宽优化
- 高频属性（CurrentAmmo、Spread）局部预测 + 定期校准
- 减少 NetMulticast，优先使用 GameplayCue（内部带复制与距离裁剪）
