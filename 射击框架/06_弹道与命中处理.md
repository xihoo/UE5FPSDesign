# 射击框架 · 弹道与命中处理

本节详细定义两种弹道模式：Hitscan（射线即时命中）与真实 Projectile（实体弹丸飞行）。武器可在数据资产中选择模式；部分武器（霰弹枪、散射榴弹）可混合（主射击使用 Hitscan，副功能使用 Projectile）。

## 1. 模式选择与数据结构

建议在武器数据资产中引入：
```cpp
UENUM(BlueprintType)
enum class EBallisticMode : uint8
{
    Hitscan UMETA(DisplayName="射线"),
    Projectile UMETA(DisplayName="实体弹丸")
};

USTRUCT(BlueprintType)
struct FWeaponBallistics
{
    GENERATED_BODY();
    UPROPERTY(EditDefaultsOnly) EBallisticMode Mode = EBallisticMode::Hitscan;
    // 通用
    UPROPERTY(EditDefaultsOnly) float Range = 10000.f; // 最大有效射程
    UPROPERTY(EditDefaultsOnly) float BaseDamage = 30.f;
    UPROPERTY(EditDefaultsOnly) float DamageFalloffStart = 3000.f; // 开始衰减距离
    UPROPERTY(EditDefaultsOnly) float DamageFalloffEnd = 8000.f;   // 结束距离（至此降到最小割合）
    UPROPERTY(EditDefaultsOnly) float DamageFalloffMinPct = 0.4f;  // 最低伤害比例
    // Hitscan 专用
    UPROPERTY(EditDefaultsOnly) int32 Pellets = 1; // 多弹丸（霰弹）
    UPROPERTY(EditDefaultsOnly) bool bAllowPenetration = false;
    UPROPERTY(EditDefaultsOnly) int32 MaxPenetrations = 0;
    UPROPERTY(EditDefaultsOnly) float PenetrationEnergyLossPct = 0.25f; // 每次穿透损失伤害百分比
    UPROPERTY(EditDefaultsOnly) bool bAllowRicochet = false;
    UPROPERTY(EditDefaultsOnly) float RicochetAngleThresholdDeg = 30.f;
    UPROPERTY(EditDefaultsOnly) float RicochetDamageLossPct = 0.5f;
    // Projectile 专用
    UPROPERTY(EditDefaultsOnly) TSubclassOf<AActor> ProjectileClass;
    UPROPERTY(EditDefaultsOnly) float InitialSpeed = 3000.f;
    UPROPERTY(EditDefaultsOnly) float GravityScale = 1.f;
    UPROPERTY(EditDefaultsOnly) float DragCoefficient = 0.f; // 空气阻力近似
    UPROPERTY(EditDefaultsOnly) bool bExplosive = false;
    UPROPERTY(EditDefaultsOnly) float ExplosionRadius = 300.f;
    UPROPERTY(EditDefaultsOnly) float ExplosionDamage = 80.f;
    UPROPERTY(EditDefaultsOnly) bool bProximityFuse = false;
    UPROPERTY(EditDefaultsOnly) float ProximityDistance = 100.f;
    UPROPERTY(EditDefaultsOnly) bool bPenetrateActors = false;
    UPROPERTY(EditDefaultsOnly) int32 ProjectileMaxPenetrations = 0;
};
```

GAS AttributeSet 可对应：Range, BaseDamage, FireRateRPM, BaseSpread, Recoil*, MagazineSize 等；Ballistics 中的配置为“默认值”，最终运行时数值以属性为准（例如 Range 被 Range 属性覆盖）。

## 2. Hitscan（射线即时命中）

### 工作流程
1. 从枪口或摄像机生成起点（支持角色瞄准偏移：第一人称用摄像机，第三人称用枪口 + 修正）
2. 应用扩散（BaseSpread、AimingSpreadMultiplier、移动/跳跃附加）
3. 对于 Pellets 次数循环：
   - 计算方向 + 射程端点
   - 执行线性或多段射线（用于穿透）
   - 命中结果汇总：记录第一个阻挡或多个穿透命中
4. 每次命中：计算距离衰减后的伤害 → 应用 GameplayEffect（或批量构建伤害事件）
5. 触发 GameplayCue（命中材质、血液、火花）

### 多弹丸霰弹示例
```cpp
void UFPSFirearmComponent::PerformHitscan()
{
    const int32 Pellets = Ballistics.Pellets;
    for(int32 i=0;i<Pellets;++i)
    {
        FVector Dir = ApplySpread(GetAimDirection(), CurrentSpread); // Spread 已含姿态/瞄准修正
        FireSingleHitscan(Dir);
    }
    SpawnMuzzleEffects();
}
```

### 单次射线含穿透与跳弹
```cpp
void UFPSFirearmComponent::FireSingleHitscan(const FVector& Dir)
{
    FVector Start = GetMuzzleLocation();
    float RemainingRange = GetEffectiveRange();
    int32 Penetrations = 0;
    FVector CurrentStart = Start;
    FVector CurrentDir = Dir;

    while(RemainingRange > 0.f)
    {
        FVector End = CurrentStart + CurrentDir * RemainingRange;
        FHitResult Hit;
        FCollisionQueryParams Params; Params.AddIgnoredActor(GetOwner()); Params.bTraceComplex = true; Params.bReturnPhysicalMaterial = true;
        bool bHit = GetWorld()->LineTraceSingleByChannel(Hit, CurrentStart, End, ECC_GameTraceChannel1, Params);
        if(!bHit) break;

        float TravelDist = (Hit.ImpactPoint - CurrentStart).Size();
        RemainingRange -= TravelDist;

        float Damage = ComputeDistanceDamage(TravelDist);
        ApplyHitDamage(Hit, Damage);
        TriggerImpactCue(Hit);

        if(Ballistics.bAllowPenetration && Penetrations < Ballistics.MaxPenetrations && CanPenetrate(Hit))
        {
            Penetrations++;
            Damage *= (1.f - Ballistics.PenetrationEnergyLossPct);
            CurrentStart = Hit.ImpactPoint + CurrentDir * 2.f; // 前移一点避免重复命中同表面
            continue; // 继续下一段
        }

        if(Ballistics.bAllowRicochet && ShouldRicochet(Hit, Ballistics.RicochetAngleThresholdDeg))
        {
            CurrentDir = ComputeRicochetDirection(CurrentDir, Hit.Normal);
            RemainingRange *= (1.f - Ballistics.RicochetDamageLossPct);
            CurrentStart = Hit.ImpactPoint + CurrentDir * 4.f;
            continue; // 反弹后继续
        }
        break; // 无穿透/跳弹则结束
    }
}
```

### 延迟补偿（多人网络）
服务器验证命中：
1. 保留最近 N 帧玩家位置与姿态快照（环形缓冲）
2. 客户端发射时间戳 + 方向 → 服务器倒退至近似时间快照重新执行射线
3. 若结果匹配或在容差内 → 接受命中；否则拒绝并回滚客户端预测特效

延迟补偿仅对高速低伤害武器或竞技环境启用。对高爆炸/范围武器不建议采用（可简化）。

### 伤害计算扩展
- 距离衰减：线性或曲线（可用 CurveFloat 在 GE 中实现）
- 材质加成：头部碰撞体 → 乘以 HeadshotMultiplier 属性
- 元素附加：命中触发额外元素 GE（火焰灼烧、冰减速）

## 3. Projectile（实体弹丸）

### 流程
1. Ability 激活：生成 Projectile Actor（支持客户端预测：本地先生成轻量代理，服务器确认替换为权威）
2. 设置初速度、重力、阻力参数
3. Tick：运动组件或自定义积分更新位置与速度（v += g * dt - drag * v）
4. 碰撞：OnHit → 伤害、爆炸、穿透或反弹；或 ProximityFuse → 接近目标触发引爆
5. 生命周期：命中/爆炸/飞行距离耗尽/超时（MaxLifeTime）

### 属性影响
从 AttributeSet 读取：BaseDamage, Range(可作最大飞行距离), ExplosionDamage, Recoil*（仅开火时）, Spread（初始方向偏差）

### 穿透与反弹
与 Hitscan 类似，但使用物理：
- 穿透：计算材质阻力；若剩余动能足够，继续前进（速度 *= 能量保留系数）
- 反弹：依据入射角与弹性系数调整速度向量；衰减伤害/爆炸威力

### 爆炸/范围伤害
```cpp
void AFPSProjectile::Explode()
{
    if(!Ballistics.bExplosive) return;
    TArray<FOverlapResult> Overlaps;
    FCollisionShape Sphere = FCollisionShape::MakeSphere(Ballistics.ExplosionRadius);
    GetWorld()->OverlapMultiByChannel(Overlaps, GetActorLocation(), FQuat::Identity, ECC_Pawn, Sphere);
    for(const auto& O : Overlaps)
    {
        float Dist = (O.GetActor()->GetActorLocation() - GetActorLocation()).Size();
        float Pct = 1.f - Dist / Ballistics.ExplosionRadius;
        float Dmg = Ballistics.ExplosionDamage * Pct;
        ApplyExplosionGameplayEffect(O.GetActor(), Dmg);
    }
    TriggerExplosionCue();
    Destroy();
}
```

### 客户端预测要点
- 仅在玩家本地生成视觉代理（不参与伤害判定）
- 服务器生成权威弹丸后，通过网络 ID 配对；客户端销毁代理/替换网格
- 若服务器判定提前命中（客户端仍在空中）→ 客户端立即播放命中/爆炸 Cue 并销毁代理

### 可选优化：对象池
- 对高频子弹/投射物使用对象池（Spawn -> Activate -> Deactivate），减少 GC 压力
- Projectile 类提供 Reset() 清理数据（速度、碰撞启用状态、定时器）

## 4. 共享工具函数

```cpp
float UFPSFirearmComponent::ComputeDistanceDamage(float TravelDist) const
{
    const float Start = Ballistics.DamageFalloffStart;
    const float End   = Ballistics.DamageFalloffEnd;
    const float MinPct = Ballistics.DamageFalloffMinPct;
    if(TravelDist <= Start) return Ballistics.BaseDamage;
    if(TravelDist >= End) return Ballistics.BaseDamage * MinPct;
    float Alpha = (TravelDist - Start) / (End - Start);
    float Pct = FMath::Lerp(1.f, MinPct, Alpha);
    return Ballistics.BaseDamage * Pct;
}
```

## 5. GAS 集成与伤害应用

推荐在 Fire Ability / Projectile Ability 内部：
1. 构建 FGameplayEffectSpec：基础伤害、元素标签、暴击（依据属性）
2. 调用 ASC->ApplyGameplayEffectSpecToTarget(TargetASC)
3. 对多命中列表批处理：循环构建或使用聚合 GE（AreaDamage）

命中事件可发布 GameplayEvent（Tag: Event.Weapon.Hit）供其他能力监听（吸血、击杀奖励）。

## 6. 调试与性能

Exec 命令建议：
- `BallisticsDebug 1`：显示射线、弹丸轨迹、爆炸范围
- `BallisticsProfile`：统计过去 N 秒命中调用次数/平均耗时

性能要点：
- 优先使用简单 TraceChannel（减少复杂物理材质检测）
- 霰弹一次性批量构建射线（DrawDebugLine 可开关）
- 对爆炸 Overlap 结果去重（同 Actor 多个组件只处理一次）

## 7. 小结

Hitscan：低延迟、适合自动枪/霰弹/精准射击；可扩展穿透、跳弹、延迟补偿。
Projectile：真实物理路径，适合榴弹/火箭/特殊效果；支持爆炸、引信、实体交互。
两者共享伤害与属性体系，通过 GAS 统一冷却/资源/标签管理。
