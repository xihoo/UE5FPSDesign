# 射击框架 · 概述与设计原则

本文档概述基于 SKG Shooter Framework 思想并深度集成 GAS 的射击系统。该框架负责武器管理、射击机制、弹道、后坐力、瞄准、网络与 UI 等核心能力。

## 设计原则

1. 模块化组件：武器由多个独立组件组合，职责清晰，便于替换与扩展
2. GAS 深度集成：所有射击相关动作通过 GameplayAbility 实现，数值经 AttributeSet 管理
3. 数据驱动：武器参数、附件与被动通过 DataAsset 与 GameplayEffect 配置
4. 多人优先：复制策略、带宽与客户端预测优先考虑
5. 程序化动画：提供可控的武器/相机程序化动画与后坐力恢复曲线

> 统一路径：InputAction -> GameplayTag(Input.*) -> GameplayAbility(Ability.*)。武器数值（后坐力、扩散、射速等）统一进入 GAS AttributeSet，由 GameplayEffect 动态修改与叠加。
