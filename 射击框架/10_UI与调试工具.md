# 射击框架 · UI 与调试工具

## UI 绑定
- HUD 准星半径/扩散展示：监听 ASC 的 BaseSpread/ AimingSpreadMultiplier 等属性变化
- 弹药计数：CurrentAmmo/ReserveAmmo（高频数据可本地预测并定期校准）
- 瞄准状态：AimingProgress/FOV 动态展示

## 调试命令（建议）
- `WeaponAttrDump`：打印当前武器相关属性（来自 AttributeSet）
- `AbilityDump`：查看授予能力/激活状态/冷却
- `InputDump`：查看 InputAction -> AbilityTags 映射

## 故障排查要点
- 能力无法激活：检查输入标签、ASC 是否持有能力、是否被状态标签阻断
- 数值不生效：核对是否正确应用/移除基础属性 GE 与附件 GE
- 预测抖动：减少客户端强制位置/状态改写，等待服务器确认后校正
