# 基类设计 · 类层次结构总览

## 核心层次结构

```
UObject
├── UGameInstance
│   └── UFPSGameInstance
├── AGameModeBase
│   └── AFPSGameMode
├── AGameStateBase
│   └── AFPSGameState
├── APlayerController
│   └── AFPSPlayerController
├── APlayerState
│   └── AFPSPlayerState
├── APawn
│   └── ACharacter
│       └── AFPSCharacterBase
│           ├── AFPSPlayerCharacter
│           └── AFPSAICharacter
└── AAIController
    └── AFPSAIController
```

## 责任分层概述

- GameInstance：全局持久化与跨关卡数据。
- GameMode：服务器规则、流程控制、生成/波次。
- GameState：可复制全局状态快照。
- PlayerController：输入/相机/玩家 UI 桥接。
- PlayerState：玩家统计与经济数据复制。
- CharacterBase：角色公共功能 + GAS 集成。
- PlayerCharacter：玩家独有输入、第一人称相机、武器接口。
- AICharacter：行为状态、仇恨、掉落。
- AIController：决策与感知、行为树、黑板。
