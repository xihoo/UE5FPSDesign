# 基类设计 · 概述与设计原则

## 概述

本文档定义了 UE5 FPS 多人 PVE 项目的核心类层次结构。所有基类均采用 C++ 实现，并深度集成 Gameplay Ability System (GAS)，为各系统提供统一的基础架构。

## 设计原则

1. GAS 优先集成：所有角色与游戏逻辑基类集成 AbilitySystemComponent。
2. 网络复制支持：自设计之初即考虑多人状态同步与带宽优化。
3. 组件化架构：组件分离关注点，提升复用与可测试性。
4. 数据驱动配置：通过 DataAsset/配置文件注入行为与常量。
5. 扩展性设计：预留扩展点、接口化，便于子类定制。
