# 基类设计 · 数据结构与网络策略

## FFPSGameSettings

```cpp
USTRUCT(BlueprintType)
struct FFPSGameSettings
{
    GENERATED_BODY()
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Audio") float MasterVolume = 1.0f;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Audio") float MusicVolume = 0.7f;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Audio") float SFXVolume = 1.0f;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Graphics") int32 ResolutionX = 1920;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Graphics") int32 ResolutionY = 1080;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Graphics") bool bFullscreen = true;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Graphics") int32 GraphicsQuality = 3; // 0-3
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Gameplay") float MouseSensitivity = 1.0f;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Gameplay") bool bInvertYAxis = false;
    UPROPERTY(EditAnywhere, BlueprintReadWrite, Category="Gameplay") float FOV = 90.0f;
};
```

## 网络复制策略

角色：
- 位置/旋转：`CharacterMovement` 内置复制。
- Health/Shield：GAS AttributeSet 自动复制。
- Weapon State：`ReplicatedUsing` 自定义通知。
- Abilities：GAS 内部同步（Spec、Cooldown、Tags）。

游戏状态：
- Phase：`ReplicatedUsing` + RepNotify。
- Wave/Enemies/Kills：标准复制。
- 时间戳：浮点复制用于客户端 UI 计算。

优化：
- 条件复制 (COND_OwnerOnly) 降低带宽。
- 合理降低不重要属性更新频率。
- 客户端预测输入/射击，服务器权威校正。

延迟与预测：
- 射击类能力使用 LocalPredicted 执行策略。
- 服务器重算关键命中（参见弹道文档延迟补偿章节）。

带宽控制：
- 避免频繁 RepNotify 驱动重型逻辑；仅在数值实际变化时处理。
