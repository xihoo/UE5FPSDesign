# 交互系统设计文档

## 概述

本文档定义了游戏中的交互系统架构，包括物品拾取、NPC对话、机关触发、商店购买等各种交互行为。交互系统提供统一的交互接口和提示UI。

## 设计原则

1. **统一交互接口** - 所有可交互对象实现统一接口
2. **上下文敏感** - 根据对象类型显示不同交互提示
3. **优先级系统** - 多个可交互对象重叠时选择优先级最高的
4. **网络同步** - 确保多人游戏中交互同步
5. **GAS集成** - 交互行为可以触发GameplayAbility

## 核心架构

### 接口和组件

```
IInteractable (交互接口)
├── GetInteractionPrompt()
├── CanInteract()
├── OnInteract()
└── GetInteractionPriority()

UFPSInteractionComponent (交互组件)
├── 检测可交互对象
├── 执行交互
├── 显示交互提示
└── 网络复制
```

## 核心实现

### 1. IInteractable接口

```cpp
UINTERFACE(MinimalAPI, Blueprintable)
class UInteractable : public UInterface
{
    GENERATED_BODY()
};

class IInteractable
{
    GENERATED_BODY()
    
public:
    // 获取交互提示文本
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    FText GetInteractionPrompt(AActor* InteractingActor) const;
    
    // 是否可以交互
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    bool CanInteract(AActor* InteractingActor) const;
    
    // 执行交互
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    void OnInteract(AActor* InteractingActor);
    
    // 交互持续时间（0=即时交互）
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    float GetInteractionDuration() const;
    
    // 交互优先级（高优先级优先显示）
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    int32 GetInteractionPriority() const;
    
    // 交互距离
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interaction")
    float GetInteractionDistance() const;
};
```

## 交互类型示例

### 1. 物品拾取

```cpp
UCLASS()
class AFPSItemPickup : public AActor, public IInteractable
{
    GENERATED_BODY()
    
public:
    // IInteractable implementation
    virtual FText GetInteractionPrompt_Implementation(AActor* InteractingActor) const override
    {
        return FText::Format(LOCTEXT("PickupPrompt", "拾取 {0}"), ItemName);
    }
    
    virtual bool CanInteract_Implementation(AActor* InteractingActor) const override
    {
        if (AFPSPlayerCharacter* Player = Cast<AFPSPlayerCharacter>(InteractingActor))
        {
            return Player->GetInventoryComponent()->CanAddItem(ItemDefinition, Quantity);
        }
        return false;
    }
    
    virtual void OnInteract_Implementation(AActor* InteractingActor) override
    {
        if (AFPSPlayerCharacter* Player = Cast<AFPSPlayerCharacter>(InteractingActor))
        {
            if (Player->GetInventoryComponent()->AddItem(ItemDefinition, Quantity))
            {
                Destroy();
            }
        }
    }
    
    virtual float GetInteractionDuration_Implementation() const override
    {
        return 0.0f; // 即时拾取
    }
    
protected:
    UPROPERTY(EditAnywhere)
    UFPSItemDefinition* ItemDefinition;
    
    UPROPERTY(EditAnywhere)
    int32 Quantity = 1;
    
    UPROPERTY(EditAnywhere)
    FText ItemName;
};
```

### 2. 门交互

```cpp
UCLASS()
class AFPSDoor : public AActor, public IInteractable
{
    GENERATED_BODY()
    
public:
    virtual FText GetInteractionPrompt_Implementation(AActor* InteractingActor) const override
    {
        if (bIsLocked)
        {
            return LOCTEXT("DoorLocked", "门已锁定");
        }
        return bIsOpen ? LOCTEXT("CloseDoor", "关门") : LOCTEXT("OpenDoor", "开门");
    }
    
    virtual bool CanInteract_Implementation(AActor* InteractingActor) const override
    {
        return !bIsLocked;
    }
    
    virtual void OnInteract_Implementation(AActor* InteractingActor) override
    {
        if (bIsOpen)
        {
            CloseDoor();
        }
        else
        {
            OpenDoor();
        }
    }
    
protected:
    UPROPERTY(Replicated)
    bool bIsOpen;
    
    UPROPERTY(Replicated)
    bool bIsLocked;
    
    void OpenDoor();
    void CloseDoor();
};
```

### 3. 商店NPC

```cpp
UCLASS()
class AFPSShopkeeper : public ACharacter, public IInteractable
{
    GENERATED_BODY()
    
public:
    virtual FText GetInteractionPrompt_Implementation(AActor* InteractingActor) const override
    {
        return LOCTEXT("TalkToShopkeeper", "与商人交谈");
    }
    
    virtual bool CanInteract_Implementation(AActor* InteractingActor) const override
    {
        return !bIsInConversation;
    }
    
    virtual void OnInteract_Implementation(AActor* InteractingActor) override
    {
        if (AFPSPlayerCharacter* Player = Cast<AFPSPlayerCharacter>(InteractingActor))
        {
            OpenShopUI(Player);
        }
    }
    
protected:
    UPROPERTY(Replicated)
    bool bIsInConversation;
    
    UPROPERTY(EditAnywhere)
    UFPSShopData* ShopData;
    
    void OpenShopUI(AFPSPlayerCharacter* Player);
};
```
