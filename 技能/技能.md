# 技能系统设计文档

## 概述

本文档定义了基于GAS的技能系统架构。技能系统负责管理玩家的主动技能、被动技能、技能升级和技能树，深度集成Gameplay Ability System实现技能效果。

## 设计原则

1. **GAS原生集成** - 技能通过GameplayAbility实现
2. **数据驱动配置** - 技能通过DataAsset配置
3. **等级和升级系统** - 支持技能等级提升
4. **技能树系统** - 支持技能前置条件和解锁链
5. **冷却和资源管理** - 统一的冷却时间和资源消耗机制

## 核心架构

### 类层次结构

```
UFPSSkillComponent (技能组件)
├── 管理技能实例
├── 处理技能学习/遗忘
├── 技能冷却管理
└── 网络复制

UFPSSkillDefinition (技能定义DataAsset)
├── 技能基础信息
├── 技能类型
├── GameplayAbility引用
├── 冷却和消耗
└── 升级曲线

UFPSSkillInstance (技能实例)
├── 引用SkillDefinition
├── 当前等级
├── 经验值
└── 技能状态

UFPGA_SkillBase (技能Ability基类)
└── 继承自UGameplayAbility
```

## 技能示例

### 1. 治疗光环（被动技能）

```cpp
UCLASS()
class UFPGA_HealingAura : public UFPGA_SkillBase
{
    GENERATED_BODY()
    
public:
    UFPGA_HealingAura()
    {
        InstancingPolicy = EGameplayAbilityInstancingPolicy::InstancedPerActor;
        NetExecutionPolicy = EGameplayAbilityNetExecutionPolicy::ServerInitiated;
        
        // 被动技能，持续生效
        bActivateOnGranted = true;
    }
    
    virtual void ActivateAbility(...) override
    {
        // 应用持续治疗效果
        if (UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo())
        {
            FGameplayEffectSpecHandle SpecHandle = MakeOutgoingGameplayEffectSpec(HealingEffect);
            if (SpecHandle.IsValid())
            {
                // 根据技能等级调整治疗量
                float HealAmount = BaseHealPerSecond * GetPowerScale();
                SpecHandle.Data->SetSetByCallerMagnitude(FGameplayTag::RequestGameplayTag("Data.Healing"), HealAmount);
                
                ApplyGameplayEffectSpecToOwner(CurrentSpecHandle, CurrentActorInfo, CurrentActivationInfo, SpecHandle);
            }
        }
    }
    
protected:
    UPROPERTY(EditDefaultsOnly)
    TSubclassOf<UGameplayEffect> HealingEffect;
    
    UPROPERTY(EditDefaultsOnly)
    float BaseHealPerSecond = 5.0f;
};
```

### 2. 火球术（主动技能）

```cpp
UCLASS()
class UFPGA_Fireball : public UFPGA_SkillBase
{
    GENERATED_BODY()
    
public:
    virtual void ActivateAbility(...) override
    {
        // 播放施法动画
        if (ActivationMontage && CurrentActorInfo)
        {
            PlayMontage(ActivationMontage);
        }
        
        // 延迟发射火球（等待动画）
        FTimerHandle TimerHandle;
        GetWorld()->GetTimerManager().SetTimer(TimerHandle, this, &UFPGA_Fireball::SpawnFireball, CastTime, false);
    }
    
protected:
    void SpawnFireball()
    {
        AActor* Avatar = GetAvatarActorFromActorInfo();
        if (!Avatar) return;
        
        // 计算发射方向
        FVector Start = Avatar->GetActorLocation();
        FVector Direction = Avatar->GetActorForwardVector();
        
        // 生成火球投射物
        FActorSpawnParameters SpawnParams;
        SpawnParams.Owner = Avatar;
        SpawnParams.Instigator = Cast<APawn>(Avatar);
        
        AFPSProjectile* Projectile = GetWorld()->SpawnActor<AFPSProjectile>(
            FireballClass,
            Start,
            Direction.Rotation(),
            SpawnParams
        );
        
        if (Projectile)
        {
            // 设置伤害
            float Damage = BaseDamage * GetPowerScale();
            Projectile->SetDamage(Damage);
            
            // 设置特效
            Projectile->SetTrailEffect(TrailEffect);
        }
        
        // 结束技能
        EndAbility(CurrentSpecHandle, CurrentActorInfo, CurrentActivationInfo, true, false);
    }
    
    UPROPERTY(EditDefaultsOnly)
    TSubclassOf<AFPSProjectile> FireballClass;
    
    UPROPERTY(EditDefaultsOnly)
    UParticleSystem* TrailEffect;
    
    UPROPERTY(EditDefaultsOnly)
    float CastTime = 0.5f;
};
```

### 3. 冲刺（切换技能）

```cpp
UCLASS()
class UFPGA_Sprint : public UFPGA_SkillBase
{
    GENERATED_BODY()
    
public:
    virtual void ActivateAbility(...) override
    {
        if (bIsActive)
        {
            // 停止冲刺
            RemoveSpeedBoost();
            bIsActive = false;
        }
        else
        {
            // 开始冲刺
            ApplySpeedBoost();
            bIsActive = true;
            
            // 持续消耗能量
            StartEnergyDrain();
        }
    }
    
protected:
    void ApplySpeedBoost()
    {
        if (UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo())
        {
            FGameplayEffectSpecHandle SpecHandle = MakeOutgoingGameplayEffectSpec(SpeedBoostEffect);
            if (SpecHandle.IsValid())
            {
                SpeedBoostHandle = ASC->ApplyGameplayEffectSpecToSelf(*SpecHandle.Data.Get());
            }
        }
    }
    
    void RemoveSpeedBoost()
    {
        if (UAbilitySystemComponent* ASC = GetAbilitySystemComponentFromActorInfo())
        {
            ASC->RemoveActiveGameplayEffect(SpeedBoostHandle);
        }
    }
    
    UPROPERTY(EditDefaultsOnly)
    TSubclassOf<UGameplayEffect> SpeedBoostEffect;
    
    FActiveGameplayEffectHandle SpeedBoostHandle;
    bool bIsActive = false;
};
```
